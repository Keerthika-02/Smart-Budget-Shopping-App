# 🛒 Smart Budget Shopping Application

A web-based application that helps users control supermarket spending by  
scanning product barcodes, tracking expenses in real time, and providing  
spending analytics with Excel export.

---

## 🚀 Features

- Set shopping budget before entering the supermarket  
- Scan product barcodes using the device camera  
- Real-time expense tracking  
- Budget exceeded alerts  
- Spending analytics dashboard  
- Export spending data to Excel (CSV)

---

## 🧰 Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** PHP  
- **Database:** MySQL  
- **Charts:** Chart.js  
- **Analytics:** Microsoft Excel (Pivot Tables, Charts)

---

## ⚙️ How to Run the Project

1. Import `database/schema.sql` into MySQL  
2. Place the project folder inside **XAMPP → htdocs**  
3. Start **Apache** and **MySQL** from XAMPP  
4. Open `index.html` in your browser
